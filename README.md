# entities-multiplayer-fabric-xr-dev

A superproject that pins the engine fork, the XR interaction addon, its test project and the libraries they use as submodules.

## What it is for

Each submodule is its own repository; this one records which of their revisions work together. `AGENTS.md` carries the notes for building the engine and running the project.

## Build and run

    git submodule update --init --recursive

Then build the engine in its submodule as that repository describes.
